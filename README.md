# المرجع السعودي للأجور

تطبيق ويب لحساب **التكلفة الفعلية للموظف على المنشأة** في السعودية، ومعها وضعه النظامي: التأمينات الاجتماعية، ونطاقات، والمقابل المالي، والمهن المقصورة على السعوديين. لكل رقم حكمه ومصدره الرسمي ودرجة ثبوته. صُمم لمنشآت متعددة، لكل منشأة بياناتها وصلاحياتها المعزولة.

> هذا المستودع لا يحتوي بيانات حقيقية. كل البيانات فيه وهمية، ولا تُستخدم بيانات حقيقية قبل اعتماد الصلاحيات والعزل والنسخ الاحتياطي.

## المكونات

| المسار | المحتوى |
|---|---|
| `engine.js` | محرك الحساب: المصدر الوحيد للمعادلات، يستخدمه التطبيق والنموذج والاختبارات |
| `app/` | التطبيق: الدخول، والمنشآت، والموظفون، ولوحة المنشأة، والأحكام والمصادر |
| `قاعدة-البيانات/` | قاعدة البيانات (`schema.sql`): الجداول والأدوار وسياسات عزل المنشآت، واختباراتها المحلية |
| `tools/` | البناء، والبيئة المحلية، واختبارات الأمان والمتصفح |
| `fixture.json` | منشآت وهمية مع القيم التي حسبها ملف Excel المرجعي لها |
| `match.cjs` | مطابقة المحرك مع قيم Excel |
| `النموذج.html` | النموذج الأولي (صفحة واحدة دون خادم)، محفوظ كما اعتُمد |

## البنية

- **الواجهة:** صفحات ثابتة (HTML وJavaScript دون إطار عمل أو أداة تجميع)، بخط IBM Plex Sans Arabic، من اليمين، تعمل على الجوال.
- **الدخول وقاعدة البيانات:** Supabase (PostgreSQL مع Supabase Auth). التسجيل الذاتي مغلق: لا يدخل إلا من يضيفه مالك النظام.
- **العزل:** تفرضه قاعدة البيانات بسياسات الصفوف (RLS)، لا الشاشات. المستخدم لا يقرأ منشأة ليس عضوًا فيها ولو عرف معرّفاتها أو عدّل الطلبات يدويًا.
- **الأدوار:** مالك النظام، ومدير المنشأة، والمحرر، والمطّلع. كل تعديل يُسجَّل في سجل لا يُعدَّل ولا يُحذف.
- **حارس البيانات الوهمية:** قيد في قاعدة البيانات يرفض أي منشأة غير وهمية في هذه المرحلة.
- **المفاتيح:** الواجهة تحمل المفتاح العام فقط، والبناء يرفض أي مفتاح سري. المفاتيح السرية في إعدادات البيئة، لا في المستودع.

## الاختبارات

```
node match.cjs                                   # المحرك مقابل Excel، وتطابق المحرك المضمّن في النموذج
bash قاعدة-البيانات/run-tests.sh                  # عزل الصلاحيات على PostgreSQL محلي
bash tools/local-stack.sh start                  # بيئة محلية: PostgreSQL + Supabase Auth + PostgREST
set -a; . /tmp/saudi-comp-stack/env; set +a
node tools/live-tests.cjs                        # الأمان والدقة عبر تسجيل الدخول الفعلي
node tools/build.cjs --url http://app.test:54321 --anon "$SB_ANON_KEY"
node tools/e2e.cjs http://app.test:54321/        # اختبار الواجهة في المتصفح
bash tools/local-stack.sh stop
```

على مشروع Supabase الحقيقي: `SUPABASE_ACCESS_TOKEN` و`SUPABASE_PROJECT_REF` في البيئة، ثم `node tools/supabase.cjs setup` و`node tools/live-tests.cjs`.

## النشر

يبني الموقع `node tools/build.cjs` إلى `dist/` من `SUPABASE_URL` و`SUPABASE_ANON_KEY`، ومعه رؤوس الأمان في `dist/_headers`.
